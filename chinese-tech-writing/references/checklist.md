# 交付前检查清单

## 0. 怎么用

1. 先跑机器检查，消灭机械错误。
2. 再人工过两遍：第一遍看事实和结构，第二遍看句子和标点。
3. 只改错，不加内容；改动超出用户要求时，先说明再动手。

## 1. 机器检查

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File <skill目录>\scripts\check-style.ps1 -Path <文档或目录>
```

Windows 默认执行策略禁止运行脚本，所以要带 `-ExecutionPolicy Bypass`。已安装 PowerShell 7 时，把 `powershell` 换成 `pwsh`，并去掉这个参数。故意保留错误示例的段落，可以用 `<!-- style-check: off -->` 和 `<!-- style-check: on -->` 包起来。

| 编号 | 检查项 | 处理 |
| --- | --- | --- |
| S01 | 中英文之间缺空格 | 必改 |
| S02 | 数字与汉字的间距 | 全文统一，二选一 |
| S03 | 全角数字或全角字母 | 必改 |
| S04 | 中文里的半角标点 | 必改 |
| S05 | 重复标点 | 必改 |
| S06 | 非标准省略号 | 必改 |
| S07 | 全角标点旁的空白 | 一般必改；Markdown 语法需要的空格除外 |
| S08 | 标题跳级 | 必改 |
| S09 | 标题末尾点号 | 必改；问号、叹号视语气保留 |

脚本会跳过代码块和行内代码，不会把代码里的标点当成问题。

## 2. 内容与事实

- [ ] 命令、参数、返回值、字段名与代码或接口一致
- [ ] 示例可以直接运行，输出与文中描述一致
- [ ] 版本号、日期、链接有效
- [ ] 术语和产品名统一；英文缩写首次出现有全称
- [ ] 没有未标注的“待确认”内容；不确定的事实已删除或标注

## 3. 结构

- [ ] 标题层级不跳级，最多四级
- [ ] 同级标题没有孤立编号，子标题不与父标题同名
- [ ] 一章只解决一个问题，章节顺序符合读者的使用路径
- [ ] 长文有目录；目录链接可用

## 4. 段落

- [ ] 每段一个主题，中心句在段首
- [ ] 段落不超过七行，最佳不超过四行
- [ ] 段落之间有空行，段首无空白
- [ ] 列表项语法一致，层级不超过两层

## 5. 句子与语气

- [ ] 单句以 20 字以内为主，没有超过 40 字的句子
- [ ] 逗号长句不超过 100 字或 3 行
- [ ] 主动语态，肯定句，没有双重否定
- [ ] 没有“进行、加以、予以 + 名词”的空动词结构
- [ ] 的、地、得使用正确
- [ ] 代词指代唯一明确
- [ ] 没有感叹号连用、口语、网络用语、夸张修辞

## 6. 标点与排版

- [ ] 中文语句用全角标点；整句英文用半角标点
- [ ] 点号不在行首，也不在标题末尾
- [ ] 省略号是 `⋯⋯`，破折号是 `——` 或 `——`
- [ ] 数值范围用 `～` 或 `—`，复合词和图表编号用 `-`
- [ ] 中文与英文之间有且只有一个半角空格；全角标点两侧无空格
- [ ] 数字半角，千分位正确，货币符号或单位写法统一
- [ ] 代码、命令、路径、配置项用行内代码

## 7. 引用与文件

- [ ] 引用第三方内容注明出处；全文转载在开头注明
- [ ] 外部图片来源已标注
- [ ] 文件名全小写、半角、连字符，无空格和中文
- [ ] 相对链接正确，锚点与标题一致

## 8. 交付说明

交付时用三句话说明：

1. 改了什么：按“事实、结构、句子、标点、格式”列出主要类型和数量。
2. 保留了什么：作者的特殊写法、品牌写法、无法确认但未改的内容，以及原因。
3. 还需要什么：待确认事实、缺失素材、建议的下一步。

## 9. 快速红线

出现以下任一情况，不交付：

- 示例跑不通，或输出与描述不符。
- 术语前后不一致。
- 标题跳级或有孤立编号。
- 超过 40 字的长句未拆。
- 中英文混排、全角半角错误成片出现。
- 引用了外部内容但没有出处。
